## Purpose

论文评估支撑能力：通过评估脚本对同一组企业问答分别执行纯 LLM 与 RAG 回答，输出准确率对比，支撑"RAG 较纯 LLM 提升 35 个百分点"结论。

## ADDED Requirements

### Requirement: 评估脚本输出准确率对比
系统 SHALL 提供评估脚本 `benchmark.py`，对同一组 20–30 道企业问答（答案源自知识库文档），分别以纯 LLM 与 RAG 两种模式回答，输出两模式准确率对比表。

#### Scenario: 生成对比表
- **WHEN** 运行评估脚本执行同一组题目
- **THEN** 脚本输出纯 LLM 与 RAG 的准确率对比表（题目数、答对数、准确率）

#### Scenario: 评估题目与参考答案可维护
- **WHEN** 评估题目或参考答案更新
- **THEN** 脚本从数据文件加载题目与参考答案，无需改脚本逻辑

### Requirement: 评估可复现
系统 SHALL 使评估脚本的输入（题目集、知识库版本、模型配置）与输出可记录，保证同一组题目多次运行结果可复现对比。

#### Scenario: 结果可复现
- **WHEN** 以相同输入再次运行评估脚本
- **THEN** 输出准确率与首次运行一致（模型确定性范围内）
